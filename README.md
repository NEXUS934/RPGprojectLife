# RPGprojectLife
O RPGprojectLife, também chamado de NEXUS, é um código main em desenvolvimento que busca vincular a simulação de RPG para a rotina monótona da vida, contento Dashboard com Análise em tempo real, skill tree, classes, missões e outros; baseando-se principalmente no estilo Cyberpunk: com hackers, monges, executores e outras funcionalidades.
